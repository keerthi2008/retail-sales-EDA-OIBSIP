# retail-sales-EDA-OIBSIP

Retail Sales Data Analysis using Excel with interactive dashboard, insights, and recommendations.

📊 Retail Sales EDA Dashboard

📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on retail sales data using Excel. It focuses on analyzing customer behavior, product performance, and sales trends.

📂 Dataset

The dataset contains:


Transaction ID

Date

Customer ID

Gender

Age

Product Category

Quantity

Price per Unit

Total Amount

⚙️ Steps Performed

Data Cleaning (removed duplicates, fixed errors)

Created new columns (Month, Year, Age Group)

Built Pivot Tables

Created interactive Dashboard

📊 Dashboard Features

KPI Cards (Total Sales, Orders, Avg Sales)

Sales Trend (Monthly)

Category Analysis

Gender & Age Group Analysis

Slicers for filtering

🔍 Key Insights

Electronics & Clothing are top-performing categories

Senior customers contribute highest sales

Sales peak in specific months

💡 Recommendations


Focus on high-performing products

Improve low-performing categories

Target key customer segments

🛠 Tools Used


Microsoft Excel

Pivot Tables

Charts & Slicers
